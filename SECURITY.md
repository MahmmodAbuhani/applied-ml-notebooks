# Security Policy

## Reporting A Vulnerability

Please use the repository's **Security** tab and select **Report a vulnerability** to send a private report through GitHub.

If private vulnerability reporting is unavailable, open a minimal GitHub issue asking the maintainer for a private reporting channel. Do not include exploit details, credentials, personal data, or other sensitive information in a public issue.

A private report may include the affected file or workflow, the observed impact, and clear reproduction steps when it is safe to do so. Public disclosure should wait until a fix or safe mitigation is available.

## Scope

This repository contains educational notebooks, local demo code, and GitHub Actions workflows. It does not operate a production service or collect user data.
