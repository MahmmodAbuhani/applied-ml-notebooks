03 / Method

The browser does the same math

This is not a hand-tuned imitation. A deterministic exporter records the fitted preprocessing statistics, one-hot categories, coefficients, and intercepts.

  1. 01Verify source

    Pin the public CSV by commit and SHA-256 before fitting.

  2. 02Export model

    Version the exact scaler, category order, coefficients, and intercepts.

  3. 03Prove parity

    Compare JavaScript with Python probabilities, logits, warnings, and explanations.

04 / Boundary

A useful model is still a bounded model.

Palmer Penguins is compact, curated teaching data. The explorer warns when a numeric input leaves the observed range, but a warning is not uncertainty quantification and an in-range value is not evidence of field reliability.

Island and year encode collection context. Their model contributions should not be interpreted as biological causes. No data is collected, stored, or sent to a prediction service. The calculation stays in this browser.
